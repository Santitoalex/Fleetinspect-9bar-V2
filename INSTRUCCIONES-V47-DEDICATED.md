# FleetInspect 9Bar - Dedicated v47

Esta version cambia toda la interfaz visual de forma mas fuerte.

## Cambios principales

- Admin con interfaz dedicada tipo centro de operaciones.
- Sidebar compacto oscuro con navegacion por iconos.
- Cabecera superior mas profesional con logo, busqueda, usuario y acciones.
- Panel principal con hero oscuro 9Bar y estados operativos.
- Tarjetas, filtros, metricas y secciones con estilo mas sobrio y empresarial.
- Driver app con estilo mas dedicado para uso diario en movil.
- Pantalla inicial del conductor mas limpia y compacta.
- Pantalla de fotos mantiene el modo profesional v46 y recibe ajustes visuales mas dedicados.
- Cache actualizado a v47 para forzar que Render/movil carguen los cambios.

## Como publicar

1. Sube todos los archivos de esta carpeta al repo de GitHub.
2. En Render pulsa Manual Deploy > Deploy latest commit.
3. Abre la web en modo incognito o borra cache del sitio si sigues viendo la version antigua.

## Supabase

No hace falta cambiar Supabase. Se queda donde esta.

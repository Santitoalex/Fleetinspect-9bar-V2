FleetInspect 9Bar - version v48

Esta version rehace la interfaz visual de admin y driver sin cambiar la base de datos ni la logica principal.

Cambios principales:
- Admin con estilo de centro de operaciones: sidebar oscuro, topbar limpia, hero profesional, metricas compactas y tarjetas operativas.
- Secciones DRP3 / DSU1, rutas, usuarios, reportes, IA y estado del sistema conservan los mismos IDs para no romper funciones.
- Driver con interfaz de app movil: cabecera 9Bar, inicio mas claro, formulario compacto y pantalla de camara mas profesional.
- Cache PWA actualizada a v48 para forzar carga nueva en Android/iPhone.

Despues de subir a GitHub:
1. En Render abre el servicio Fleetinspect-9bar.
2. Pulsa Manual Deploy.
3. Usa Clear build cache & deploy.
4. Abre /admin.html?v=48 y /index.html?v=48.
5. Si el movil tenia la app instalada, desinstalala y vuelve a instalarla.
